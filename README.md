# Agentes de IA com LLMs

Ementa:

A disciplina capacita o aluno a projetar, construir e publicar sistemas inteligentes baseados em
Grandes Modelos de Linguagem (LLMs). Partindo do funcionamento prático dos modelos modernos. A disciplina avança por engenharia de prompt, integração com APIs, busca semântica, recuperação aumentada por geração (RAG), fine-tuning, agentes autônomos,
sistemas multi-agent. Atenção constante a aspectos éticos e de responsabilidade em IA.
